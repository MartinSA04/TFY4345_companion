# TFY4345 Klassisk mekanikk

Interaktivt kompendium i [TFY4345](https://www.ntnu.no/studier/emner/TFY4345) ved NTNU:
moduler med quiz, flashcards, formelsamling og begreper. Les det på
**[klasmek.martinsundal.no](https://klasmek.martinsundal.no)**.

Bygget på [StudyCompanion](https://github.com/MartinSA04/StudyCompanion);
dette repoet inneholder kun innhold (`content/`).

## Kjør lokalt

```bash
pnpm install
pnpm dev
```
